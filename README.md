# Sua Saúde, Seu Caminho

Site educativo desenvolvido como projeto acadêmico para facilitar o acesso a informações sobre o Sistema Único de Saúde (SUS).

## Objetivo

Ajudar a comunidade a entender onde buscar atendimento e como consultar informações sobre serviços de saúde. O conteúdo é informativo e **não substitui avaliação médica**.

## Funcionalidades

- Explicação sobre SUS, UBS, UPA e hospitais.
- Orientação inicial sobre onde buscar atendimento conforme sintomas e situações.
- Consulta de unidades de saúde em Biguaçu, Palhoça, Florianópolis e São José (SC), com atalhos para mapas e contatos demonstrativos.
- Informações sobre vacinas por faixa etária, medicamentos e outros itens do SUS.
- Orientações sobre encaminhamentos e marcação de consultas.
- Interface adaptada para computador e celular.

## Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo das páginas (`index.html`).
- **CSS3:** cores, layout e responsividade (`style.css`).
- **JavaScript:** navegação, filtros e interações (`script.js`).
- **SVG:** ilustração da página inicial (`comunidade.svg`).

## Como executar no VS Code

1. Extraia o arquivo ZIP.
2. Abra a pasta do projeto no Visual Studio Code em **Arquivo > Abrir Pasta**.
3. Abra `index.html` no navegador. Você também pode usar a extensão **Live Server**.
4. Mantenha os quatro arquivos na mesma pasta para que os estilos, funções e imagem carreguem corretamente.

## Como publicar

No Netlify, envie a **pasta completa** do projeto (com `index.html` na raiz). Não é necessário instalar dependências nem executar compilação.

## Avisos

O site é um **protótipo acadêmico**. Cadastros de unidades, horários, disponibilidade de medicamentos, vacinas e regras de atendimento precisam de conferência com fontes oficiais antes de uso público. Os contatos de WhatsApp e e-mail são demonstrativos e não representam canais reais das unidades.
